# Symbol Reference for gmail.mjml_types

This document maps component symbols to their names.

## Symbol Table

**A:** `ą` = AccordionBlock

**B:** `Ƀ` = ButtonBlock

**C:** `ȼ` = CarouselBlock, `©` = Column, `¢` = ColumnsBlock

**D:** `đ` = DividerBlock

**E:** `ε` = EmailSpec

**F:** `ƒ` = FooterBlock

**H:** `Ħ` = HeaderBlock, `ħ` = HeroBlock

**I:** `ɨ` = ImageBlock

**S:** `ʂ` = SocialBlock, `ş` = SpacerBlock

**T:** `ƭ` = TableBlock, `τ` = TextBlock
